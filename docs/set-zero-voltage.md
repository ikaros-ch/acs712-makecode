# Set zero voltage

Manually set the zero-current voltage seen by the micro:bit pin, in mV.

```sig
acs712.setZeroVoltage(1250)
```

## Parameters

* **millivolts**: pin voltage with no current flowing

## Example

```blocks
acs712.setZeroVoltage(1250)
```

```package
acs712=github:ikaros-ch/acs712-makecode
```

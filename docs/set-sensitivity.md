# Set sensitivity

Set the sensor sensitivity in mV/A, for boards not in the model list.

```sig
acs712.setSensitivity(185)
```

## Parameters

* **mvPerA**: sensitivity in millivolts per amp

## Example

```blocks
acs712.setSensitivity(185)
```

```package
acs712=github:ikaros-ch/acs712-makecode
```

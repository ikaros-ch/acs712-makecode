# Read current

Read DC current in amps. Negative when current flows the other way.

```sig
acs712.readCurrent(AnalogPin.P0)
```

## Parameters

* **pin**: the analog pin the sensor OUT is wired to

## Example

```blocks
acs712.readCurrent(AnalogPin.P0)
```

```package
acs712=github:ikaros-ch/acs712-makecode
```
